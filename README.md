# Dot Sequencer

一个「小球音序器」：小球在音高网格上运动，走过格点即发声。9 个声部按 **音区（低/中/高）× 节奏（1/2 · 1/4 · 1/8 · 1/16）** 铺开，内置 20 种音色，也能把音符输出给 DAW 里的任何音源。

- 格式：**VST3 + Standalone（Windows x64）**
- 当前版本：**0.2.9**
- 下载：**[Releases](../../releases/latest)**
- 说明书：**Dot-Sequencer-Manual-0.2.9.pdf**（13 页，也在 Releases 里）

## 下载与安装

**VST3** —— 下载 `Dot-Sequencer-0.2.9-Windows-VST3.zip`，解压后把 `Dot Sequencer.vst3` 整个文件夹放到

```
C:\Program Files\Common Files\VST3\
```

然后在 DAW 里重新扫描插件（插件名 `Dot Sequencer`，分类 Instrument）。若之前加载过旧版本，请**完全退出 DAW 再打开** —— Windows 会锁定已加载的 VST3。

**Standalone** —— 直接运行 `Dot-Sequencer-0.2.9-Windows-Standalone.exe`，不需要 DAW。

**说明书** —— 下载 `Dot-Sequencer-Manual-0.2.9.pdf`。第一次用先看第 2 章：Standalone 的音频缓冲要手动设一次（512 或 1024），否则可能听到咔哒声。

无需安装、无需运行库；两个安装包都是自包含的，说明书是单独的 PDF。

## 主要特性

| | |
|---|---|
| 声部 | 9 个，每个独立音区 / 节奏 / 音色 / 触发概率 / 音量 / 独奏 / 静音 / 跟随和弦 / MIDI 通道（默认 CH1–CH9） |
| 音色 | 20 种，分低音区 · 中音区 · 高音区 · 氛围合奏 · 弦乐组 |
| 运动 | 布朗 / 直线 / 圆周呼吸 / 黄金三角，四种轨迹 |
| 和声 | 18 组和弦进行（4 类）、12 调、调内音阶网格、和弦跟随（每声部可开关） |
| 输出 | 内置音源（预览）+ 宿主 MIDI 输出 + 硬件 MIDI 端口 |
| 效果 | BPM 同步延时（附点八分）+ 混响 |
| 同步 | 跟随宿主 BPM 与播放/停止 |
| 外观 | 深色 / 浅色两套主题（标题栏按钮切换，独立版可按 `T`），选择跟人走、不写进工程 |

## 0.2.9 更新要点（界面精修版）

**配色重做（清爽化）**

- 深色从"纯黑"抬成**深海军**：机身 / 舞台 / 卡片三级明度台阶均匀，走带行不再是一条黑色断层。
- 浅色换成**冷调纸白**：舞台是真正的白纸，顶部灰雾、音点糊边全部去掉。
- 钢青强调色提纯为清透青蓝，不再像"水洗过的雾"。

**整体放大**

- 版面在 1080 × 860 的设计坐标里调平，再**整体等比放大**到窗口（约 1.77 倍、内容居中）。字号、控件、间距一起变大 —— 高分屏上不再是"大窗口里飘着小字"。

**视觉去脏**

- 音名重影修复：点亮态字形单独走离屏层，不再出现双描边；两套字号口径统一。
- 音点 / 声部小球去掉描边与边缘细环。
- 舞台圆角处的线头、标题条悬空基线删除。
- 声部卡左缘色条加宽为明确的"通道色标"。

其余功能与 0.2.8 一致。

## 关于这个仓库

本仓库**只发布编译好的二进制**（`Releases`），不包含插件源代码。

Dot Sequencer 最初是一个单文件 HTML 网页版音序器（纯 Web Audio），后来重写为 JUCE 8 的原生 VST3 插件；HTML 版本已停止维护。
