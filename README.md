# Dot Sequencer

一个「小球音序器」：小球在音高网格上运动，走过格点即发声。9 个声部按 **音区（低/中/高）× 节奏（1/2 · 1/4 · 1/8 · 1/16）** 铺开，内置 20 种音色，也能把音符输出给 DAW 里的任何音源。

- 格式：**VST3 + Standalone（Windows x64）**
- 当前版本：**0.2.0**
- 下载：见仓库右侧 [Releases](../../releases) 页

## 安装

**VST3**：下载 `Dot-Sequencer-0.2.0-Windows-VST3.zip`，解压后把 `Dot Sequencer.vst3` 整个文件夹放到

```
C:\Program Files\Common Files\VST3\
```

然后在 DAW 里重新扫描插件（插件名 `Dot Sequencer`，分类 Instrument）。若之前加载过旧版本，请**完全退出 DAW 再打开** —— Windows 会锁定已加载的 VST3。

**Standalone**：直接运行 `Dot Sequencer.exe`，不需要 DAW。

## 主要特性

| | |
|---|---|
| 声部 | 9 个，每个独立音区 / 节奏 / 音色 / 音高色 / 音量 / 独奏 / 静音 / MIDI 通道 |
| 音色 | 20 种，分低音区 · 中音区 · 高音区 · 氛围合奏 · 弦乐组 |
| 运动 | 布朗 / 直线 / 圆周呼吸 / 黄金三角，四种轨迹 |
| 和声 | 8 组和弦进行、12 调、调内音阶网格、和弦跟随（每声部可开关） |
| 输出 | 内置音源（预览）+ 宿主 MIDI 输出 + 硬件 MIDI 端口 |
| 效果 | BPM 同步延时（附点八分）+ 混响 |
| 同步 | 跟随宿主 BPM 与播放/停止 |

## 0.2.0 更新要点

- 修正部分音色（如「空灵」）在高音区的抖动破音：近邻失谐分音的拍频钳到 5Hz 以内
- 发声单元池 48 → 96，抢声部改为按「包络 + 释放段 + 起音年龄」排序，修复声部开多后个别声部被吞音
- 总线按同时在响的音数做 1/√N 归一，声部开多不再把软限幅顶出破音
- 拖速度时延时读指针平滑插值，不再有咔哒声

## 关于这个仓库

最初是一个单文件 HTML 网页版音序器（`dots-music.html`，纯 Web Audio），后来重写为 JUCE 8 的 VST3 插件。HTML 版本已在 0.2.0 时归档并停止维护，源码保留在 git 历史里。
