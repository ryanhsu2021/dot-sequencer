# Dot Sequencer

一个「小球音序器」：小球在音高网格上运动，走过格点即发声。9 个声部按 **音区（低/中/高）× 节奏（1/2 · 1/4 · 1/8 · 1/16）** 铺开，内置 20 种音色，也能把音符输出给 DAW 里的任何音源。

- 格式：**VST3 + Standalone（Windows x64）**
- 当前版本：**0.2.2**
- 下载：**[Releases](../../releases/latest)**

## 下载与安装

**VST3** —— 下载 `Dot-Sequencer-0.2.2-Windows-VST3.zip`，解压后把 `Dot Sequencer.vst3` 整个文件夹放到

```
C:\Program Files\Common Files\VST3\
```

然后在 DAW 里重新扫描插件（插件名 `Dot Sequencer`，分类 Instrument）。若之前加载过旧版本，请**完全退出 DAW 再打开** —— Windows 会锁定已加载的 VST3。

**Standalone** —— 直接运行 `Dot-Sequencer-0.2.2-Windows-Standalone.exe`，不需要 DAW。

无需安装、无需运行库，两个包都是自包含的。

## 主要特性

| | |
|---|---|
| 声部 | 9 个，每个独立音区 / 节奏 / 音色 / 触发概率 / 音量 / 独奏 / 静音 / 跟随和弦 / MIDI 通道 |
| 音色 | 20 种，分低音区 · 中音区 · 高音区 · 氛围合奏 · 弦乐组 |
| 运动 | 布朗 / 直线 / 圆周呼吸 / 黄金三角，四种轨迹 |
| 和声 | 12 组和弦进行、12 调、调内音阶网格、和弦跟随（每声部可开关） |
| 输出 | 内置音源（预览）+ 宿主 MIDI 输出 + 硬件 MIDI 端口 |
| 效果 | BPM 同步延时（附点八分）+ 混响 |
| 同步 | 跟随宿主 BPM 与播放/停止 |

## 0.2.2 更新要点

本版是和声与交互修正，界面布局、声音参数不变，旧工程可直接继续用。

- **默认和弦进行改为七和弦**：`Imaj7-vi7-IVmaj7-V7`。默认三个声部是「低=根音 / 中=三音 / 高=七音」的 shell voicing，但旧默认是三和弦，高音声部被迫降级成五音
- **修正两个进行的实奏**：`i-VII-VI-V7` 末小节现在是真正的 G7（升导音，和声小调张力成立）；`i-bII-bVII-i` 的 bII 现在是 Db 大三（拿波里），不再是 Dm
- **和弦名与实奏对齐**：区分 `Cmaj7` / `C7` / `Cm7` / `Bdim`，进行名里的 `IV7`→`IVmaj7`、`i9`→`i7`
- **单击画布音点现在会闭音**：原来每一笔的第一个格子被去重逻辑吞掉，只有拖到第二格才生效
- **速度滑块 20–300 BPM**：与工程存档、宿主速度同一口径；174 BPM 的工程重开后不会再被夹回 120
- **界面繁忙不再拖慢节奏**：音频线程抢不到界面锁时时钟照走、下次补触发，不再永久丢时间
- **关闭插件窗后硬件 MIDI 不再留长音**：noteOff 不再只依赖界面定时器
- **加载工程后**：和弦进行下拉、密度档位、`AUTO VAR` 开关都会正确恢复

## 关于这个仓库

本仓库**只发布编译好的二进制**（`Releases`），不包含插件源代码。

Dot Sequencer 最初是一个单文件 HTML 网页版音序器（纯 Web Audio），后来重写为 JUCE 8 的原生 VST3 插件；HTML 版本已停止维护。
