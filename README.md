# Dot Sequencer

一个「小球音序器」：小球在音高网格上运动，走过格点即发声。9 个声部按 **音区（低/中/高）× 节奏（1/2 · 1/4 · 1/8 · 1/16）** 铺开，内置 20 种音色，也能把音符输出给 DAW 里的任何音源。

- 格式：**VST3 + Standalone（Windows x64）**
- 当前版本：**0.2.1**
- 下载：**[Releases](../../releases/latest)**

## 下载与安装

**VST3** —— 下载 `Dot-Sequencer-0.2.1-Windows-VST3.zip`，解压后把 `Dot Sequencer.vst3` 整个文件夹放到

```
C:\Program Files\Common Files\VST3\
```

然后在 DAW 里重新扫描插件（插件名 `Dot Sequencer`，分类 Instrument）。若之前加载过旧版本，请**完全退出 DAW 再打开** —— Windows 会锁定已加载的 VST3。

**Standalone** —— 直接运行 `Dot-Sequencer-0.2.1-Windows-Standalone.exe`，不需要 DAW。

无需安装、无需运行库，两个包都是自包含的。

## 主要特性

| | |
|---|---|
| 声部 | 9 个，每个独立音区 / 节奏 / 音色 / 触发概率 / 音量 / 独奏 / 静音 / 跟随和弦 / MIDI 通道 |
| 音色 | 20 种，分低音区 · 中音区 · 高音区 · 氛围合奏 · 弦乐组 |
| 运动 | 布朗 / 直线 / 圆周呼吸 / 黄金三角，四种轨迹 |
| 和声 | 8 组和弦进行、12 调、调内音阶网格、和弦跟随（每声部可开关） |
| 输出 | 内置音源（预览）+ 宿主 MIDI 输出 + 硬件 MIDI 端口 |
| 效果 | BPM 同步延时（附点八分）+ 混响 |
| 同步 | 跟随宿主 BPM 与播放/停止 |

## 0.2.1 更新要点

本版是稳定性与正确性更新，界面与声音参数与 0.2.0 一致，旧工程可直接继续用。

- **修复走带卡死**：速度换算出的每格采样数不是整数时（如 60 BPM、48 kHz），内部时钟可能原地不动，播放推进停止、整机无声
- **修复偶发爆音/卡顿**：音频线程不再因硬件 MIDI 输出或界面线程改动而阻塞、也不再在实时路径上分配内存
- **修复闭音丢失**：消音格状态此前没有存进工程，重开后网格会变样
- **修复网格与小球错位**：音点网格整体偏移 6 px，已对齐到同一套几何
- **修复释放段斜率**：包络释放起始电平在赋值前被读取，导致释放长度随前次参数漂移
- **修复舞台暗色同心环**：音点「水面呼吸」的环带裁剪失效，画面出现巨大暗环与空洞；呼吸改为整层单次合成的整体缓呼吸

## 关于这个仓库

本仓库**只发布编译好的二进制**（`Releases`），不包含插件源代码。

Dot Sequencer 最初是一个单文件 HTML 网页版音序器（纯 Web Audio），后来重写为 JUCE 8 的原生 VST3 插件；HTML 版本已停止维护。
